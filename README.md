# Shopping List

This is just a small shopping list terminal app. I wrote it as an exercise while learning zig. I might have done things in weird ways, and there's a good chance it's either because I was trying to practice something specific, or I just don't know any better. Probably the latter.

## Future Features

Some things that might be fun to try adding:

- Saving list to a file
- Multiple lists
- Either retaining the order in which items were added or displaying them in sorted order (probably alphabetical)
